# 武汉 Ride 自由仰俯视角

鼠标或触摸在画面空白区域拖动：左右环视，上拖仰视，下拖俯视。停车和行驶时均可使用。竖直角度保持到下一次拖动、按 R 复位或退出骑行；水平偏移继续缓慢回到骑手后方。HUD 提示 `R 视角复位`，虚拟转向、加速和刹车按钮保留独立输入。

角度以视线上仰为正，默认 -10°，限制在 -25° 至 +70°。相机围绕骑手附近的 2 米锚点计算球面位置，目标沿观察方向加上随速度变化的前视距离。正仰角下，位置绕行角取视线角的 72%，给镜头与车尾留出空间；最大仰角时仍可保留画面下方的角色参照。仰角增大时缩短跟随距离以保留地面间距，并渐进偏到侧肩，避免近距离镜头进入电动车后壳或被骑手挡住。建筑遮挡检查在位置平滑前后均保留；车辆、植物、桥塔等不增加相机障碍。

60 km/h 的距离、前视和 FOV 变化继续工作。减少动态模式保留主动仰俯，关闭原有自动摆动。R 通过相机平滑更新恢复默认构图。退出精确还原原 Orbit 位置、旋转、目标、投影、视口偏移和启用状态；下次进入不继承仰角。

`getRideState()` 新增 `cameraYawOffset`、`cameraPitch`（弧度）、`cameraPitchDegrees` 和 `cameraDistance`（米，实际镜头至锚点距离）。旧 `cameraOffset` 兼容保留。

验证命令：`npm run wuhan:camera:verify` 和 `npm run wuhan:camera:browser`。浏览器报告为 `docs/wuhan-ride-camera-qa.json`，截图保存到忽略提交的 `probe/wuhan/ride-camera-*.png`。浏览器使用真实鼠标拖动、键盘和 Chrome 触摸事件，覆盖绿地中心、武汉中心、黄鹤楼、龟山电视塔、长江大桥桥塔五处顶部投影与停驻稳定性，并人工查看截图。移动端为模拟视口，不代表实体手机验收。
